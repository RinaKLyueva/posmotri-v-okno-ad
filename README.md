# Посмотри в окно

Веб-приложение, которое показывает видео из окон в разных городах. Можно найти ролики по названию города и времени суток, а по клику на карточку — переключить видео в основном плеере.

## О проекте

Это проектная работа, в которой я верстала стили для уже работающего приложения. HTML-разметка и JavaScript-логика были готовы заранее, моя задача — написать `style.css` так, чтобы интерфейс соответствовал макету и при этом не сломалась функциональность: загрузка карточек, поиск, прелоадеры, вывод ошибок и переключение видео.

В отличие от предыдущих работ, здесь я стилизовала чужой модуль: работала с элементами, которые создаются из `<template>` скриптом, и встраивала стили так, чтобы они не мешали готовой логике.

## Что сделано

- Лейаут страницы на флексбоксах, без абсолютного позиционирования (кроме паттерна `.visually-hidden`).
- Видео и превью подогнаны под размеры через `object-fit` и `object-position`.
- Кастомные чекбоксы: браузерный чекбокс скрыт, вместо него нарисован свой, отмеченное состояние сделано через псевдоэлемент `::after` и `:checked`.
- Состояния интерактивных элементов: `:hover`, `:active`, `:focus-visible`. Обводка у поля ввода и чекбоксов появляется на лейбле через `:has(:focus-visible)` и только при навигации с клавиатуры.
- Обрезка длинного текста: название города — многоточием через `text-overflow: ellipsis`, описание — через `line-clamp`.
- Прелоадеры и блок ошибки позиционируются внутри своих контейнеров, а не поверх всей страницы.

## Технологии

- HTML5
- CSS3: Flexbox, псевдоклассы `:has()`, `:checked`, `:focus-visible`, псевдоэлементы, `object-fit`, `line-clamp`
- JavaScript (готовая логика приложения, получение данных через `fetch`)

## Как запустить

1. Склонируйте репозиторий:

   ```bash
   git clone <ссылка на репозиторий>
   ```

2. Откройте папку проекта в VS Code и запустите `index.html` через расширение Live Server. Можно открыть файл и напрямую в браузере, но с локальным сервером запросы к API работают надёжнее.

3. Для работы нужен доступ в интернет: видео и карточки загружаются с сервера `https://v-content.practicum-team.ru`.

Сборка и установка зависимостей не нужны. Проверено в Google Chrome, Firefox и Яндекс Браузере.
